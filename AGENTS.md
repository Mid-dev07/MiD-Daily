# MiD Daily Agent Operating Contract

For every UI, UX, visual, responsive, copy, accessibility, or frontend change:

1. Read `DESIGN.md`.
2. Apply `docs/ANTI_SLOP_MID_STANDARD.md`.
3. For all user-facing text, documentation, UI copy, slide copy, social/marketing copy, and code comments, run the local `skills/anti-slop/SKILL.md` and its compact spine in `skills/anti-slop/AGENTS.md`.
4. Apply the relevant current Unreal documentation under `docs/`.
5. Audit before changing implementation.
6. Prefer reuse, consolidation, replacement, then addition.
7. Finish with functional QA, accessibility QA, responsive QA, visual QA, cleanup, and regression checks.
